---
title: "Useful things do not need to shout"
date: 2026-07-28
summary: "A working rule for interfaces that must carry real information."
tags: ["interfaces", "systems"]
draft: false
---

Visual force is useful when it explains priority. It becomes noise when every item asks for the same attention.

I use a simple test: remove the treatment and check whether the structure still explains itself. If the answer is no, the problem is usually hierarchy, naming, or sequence.

Decoration can return after the structure works. It then has one job instead of five.
